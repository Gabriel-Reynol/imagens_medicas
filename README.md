# Projeto de Diferenciação de Imagens de TC de Tórax com e sem Contraste
Desenvolvimento de Algoritmo para Diferenciação de Imagens de Tomografia Computadorizada de Tórax com e sem Contraste
Descrição

Este projeto tem como objetivo desenvolver um algoritmo baseado em Inteligência Artificial (IA) para realizar a diferenciação automática entre imagens de Tomografia Computadorizada (TC) de tórax com e sem o uso de agente de contraste. A proposta visa superar as inconsistências na documentação dos exames, frequentemente encontradas nas tags DICOM, e melhorar a classificação automatizada de imagens radiológicas.

O algoritmo será treinado para identificar a presença ou ausência de contraste nas imagens de TC, e seus resultados serão comparados com as informações do cabeçalho DICOM para garantir maior confiabilidade no processo.
